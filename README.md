## 🎯 Project Overview

This project analyzes volunteer platforms to evaluate **business performance, operational efficiency, and social impact** using a structured data model.

The goal is to transform raw data into **actionable business decisions**.

---

## 🧠 Business Problem

Organizations working with volunteer platforms face key challenges:

- Which missions generate real value?
- How does volunteer experience affect success?
- Are high-impact missions financially sustainable?
- Which platforms perform best?

---

## 📊 Dataset Structure (Star Schema)

This project uses a **star schema model**:

### ⭐ Fact Table
- fact_missions_performance.csv  
  → Financial + operational metrics (Revenue, Cost, Profit, ROI, Success Score)

### 🧩 Dimension Tables
- dim_date.csv → Time analysis  
- dim_platforms.csv → Platform segmentation  
- dim_volunteers.csv → Volunteer profiles  
- dim_missions.csv → Mission characteristics  
- dim_engagement.csv → Platform engagement metrics

## 📈 Key Metrics

- Total Profit
- ROI (Return on Investment)
- Success Rate
- Mission Completion Rate
- Volunteer Performance Score
- Weighted Impact Score

---

## 🔍 Key Insights

- High-complexity missions tend to reduce ROI
- Experienced volunteers significantly improve success rates
- Some platforms generate high impact but low profitability
- Approximately 25% of missions are not profitable
- Platform performance varies significantly across regions

---

## 💡 Business Recommendations

- Focus on medium-complexity missions for optimal ROI
- Allocate experienced volunteers to critical missions
- Re-evaluate low-performing platforms
- Optimize cost structure for high-risk missions
- Improve volunteer allocation strategy
